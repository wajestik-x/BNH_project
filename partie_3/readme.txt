Les tableaux de bord Power BI (fichiers .pbix) ne sont pas encore disponibles dans ce dépôt pour les raisons suivantes :

1. Les fichiers .pbix sont binaires et ne se prêtent pas bien au contrôle de version Git (difficile de voir les modifications, conflits fréquents).

2. La taille des fichiers peut être importante une fois les données embarquées, ce qui n’est pas idéal pour un dépôt GitHub.

Les données sources (CSV), le notebook Python, les scripts SQL et la documentation sont déjà disponibles dans le dépôt.  
Les fichiers Power BI seront ajoutés ultérieurement (ou fournis séparément) une fois la version finale validée.
